# Native source review

Mode: Operate. Extend the existing Forge design system and native Work authority.

## Direction contract

THESIS: Follow an outcome into exact source evidence without forcing a delivery sequence. File changes and discussion share context; full source stays reachable.

OWN-WORLD: Existing neutral surfaces, orange selected controls, Manrope headings, system interface labels and monospace source. Flat divided panes and ordinary controls.

STORY: Find a changed file, inspect its patch or original versions, and leave a comment that remains tied to those bytes. Source identities stay secondary.

FIRST VIEWPORT: A search/filter/sort toolbar above a compact file column and flexible source pane. Changes/Before/After tabs stay beside the selected filename. On narrow screens, the scrollable file list precedes code. Selecting a line opens an inline comment composer with its exact source context.

FORM: Extend the incumbent master/detail workspace. Code-led existing-world extension; no replacement direction or decorative motion. Signature interaction: line selection keeps source and Intent discussion connected without moving the original anchor.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
