Tidewater

build: passingcrates.io v2.4.1

Tide tables and harbour-pilot windows from public gauge data. One library, one command, no network at run time once the tables are cached.

Install

# needs Rust 1.82 or newer
cargo install tidewater

Use

  1. Fetch a port's tables: tidewater fetch dover.
  2. Ask for the next safe window: tidewater window dover --draught 9.2.
  3. Plot a week: tidewater plot dover --days 7.
