The hosted build includes `/docs/`: static task guides, the packaged documentation
in a left tree and a readable column, and CLI/MCP reference generated from their
source contracts. Markdown, `/llms.txt` and `/llms-full.txt` stay available for
agents. Reading docs makes no Convex calls and does not require sign-in. First-run
help and the public page link to this destination. Account billing runs on stubs;
charging, package publication, the default login service and a public production
service are not available yet. Independent agent scorecard and
fresh-model getting-started validation remain open.
