**GitHub archive imports list in pages and resume from verified pins.** A
scheduled worker validates and writes the committed tree to R2 listing pages.
Acquisition checkpoints verified file pins. Later steps fetch remaining files
in byte-bounded Git packs. At 65,536 files and up, acquisition schedules
publication as a separate action. Publication and retry read verified pin or
State ranges and remove the scratch objects. The 2,405-file
deadline replay publishes the same digests and modes as a one-step acquisition.
A hosted Firefox-shaped import published 487,756 files in 26m11s. Its provider
billing record alone did not establish the executor memory limit.
