The dev web site is a Cloudflare Worker on the free plan at https://dev.forge.nanthai.tech (Item ef6aa22a; own
address since Item 702af738, the workers.dev address redirects there); Netlify is retired. Both dev web and dev Convex deploys start straight from Forge `main` landings via OIDC-authenticated `workflow_dispatch` (Item 8b6efb50) rather than GitHub mirror pushes, record the deployed State for receipts, `lane-history`, `wait {"deploy":...}` and **Needs you** failure notices, show the build version from `/_forge/build.json`, and run post-deploy smoke checks (build version, public-read JSON, sitemap and old `/-/` redirect). Dev web deploys only when what it serves changed, at most once per 5 minutes with one Forge-scheduled trailing flush (shortened from 20 minutes; the old 20-minute window made 23 deploys per 100 landings against 56 before). earlier address must be registered again: sign in with GitHub, add one and remove the old one. See [web site](../../development.md#web-site).
