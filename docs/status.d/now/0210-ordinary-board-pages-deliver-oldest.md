Ordinary board pages deliver oldest unread notes first with a working continuation, preserving unread Issue notes when another Lane already read the project's notes. A rolled-back server rejecting cached `laneAfter` gets one read retry without that argument; save mutations are not replayed. History and exact-note reads leave both local read positions unchanged. Default board notices preserve an exact-id read-more command when the full note does not fit, including in first-write claim context. Page hints name the originating Lane so they also work from the project root. Own-Lane notes are excluded before filling delivery pages. A failed predecessor-advice read retains the stored value only for an unchanged source pair, avoiding repeated conflict wakes without carrying advice to new heads.
