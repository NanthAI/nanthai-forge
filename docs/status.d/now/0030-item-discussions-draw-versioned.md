Item discussions draw versioned structured review batches from existing comment text,
including exact reported source pins, finding ids, severity, origin and reasoned outcomes.
Candidate review shows its recorded summary, verification declaration and check result.
A project writer can send a line note from either the unified or split diff to the
Item discussion with the exact Candidate and line pins. These remain advisory reports;
automatic cross-save anchoring and enforcement are open.
See [review findings](../../guides/review.md#structured-review-findings) and the
[land-it recipe](../../guides/agents.md#land-it).
