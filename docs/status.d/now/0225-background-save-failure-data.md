An unattended background save failure appears on the web Lane detail and Lanes board, as well as in the agent board data. It stays visible until acknowledged by a later checkout command, replaced by a newer save, retried or dismissed. The original receipt remains readable. The web views reuse their live reads and show **Dismiss** to the project owner and to the account that made the failing save when it can still write to the project. Pressing the button makes one mutation ([save API](../../operations/source-exchange.md#hosted-lane-save-api)).
