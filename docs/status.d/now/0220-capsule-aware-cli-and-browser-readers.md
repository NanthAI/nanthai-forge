Capsule-aware CLI and browser readers resolve selected terminal observations,
status, attempts, Candidate and finish-input history through a server action. The
action verifies compressed content and per-table digests, rechecks current access
after the fetch, and applies current identity redaction. Clients receive logical
replies, never capsule bytes or object grants. The default-off server setting
`FORGE_LANDING_CAPSULES=1` installs a single terminal-plus-seven-day wake for new
landings. It writes and verifies one complete private R2 capsule before bounded,
retryable removal of relocated copies. Transaction pins, metric scalars and reuse
aliases remain query-readable. Recovery exports resolve capsules through the same
authorized action; the fixture drill restores capsule-only acceptance history and
hosted source. Live relocation, billed usage and production enablement are unverified.
