The rebuilt GitHub mirror settings support owner-person Pause, Resume and
confirmed Disconnect, using the project policy and binding transactions. Import preselects a two-way
mirror. Web and CLI share the mirror status sentence; paused links retain their
repository and direction. Resume wakes retained work and publishes the combined
paused window in one current-main catch-up commit listing covered landing subjects
and short receipt ids (first 20, then a remainder count), without waiting for another
landing. Pre-Pause off mirrors keep their Turn the mirror on panel and recorded
direction. Owner CLI recovery remains available for enabled mirrors; Pause,
un-pause and Disconnect require the person ([mirror workflow](../../workflows.md#automatic-main-mirror)).
