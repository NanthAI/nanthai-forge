Device credentials cannot reveal Secret Object values, permanently delete Secret
Objects or projects, or register machine runners and receive check-signing keys.
Secret Object creation, rotation, grants, disabling and trash require an
unrestricted device or a person. Import starts and saved-view writes use the same
account write rule. Membership approval readers
support exact-change person review; deploy these backend and web readers before enabling
membership request writers. CLI environment credentials are bound to trusted deployment
origins. Details: [security](../../security.md).
