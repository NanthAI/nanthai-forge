The owner person trashes, restores and permanently deletes projects. A device needs project
write access to request a rename for the owner. Account cleanup and machine runner registration
with check-signing keys also require the account holder. Import starts and saved-view writes use
the account write rule: an unrestricted device or a person. Membership approval readers
support exact-change person review; deploy these backend and web readers before enabling
membership request writers. CLI environment credentials are bound to trusted deployment
origins. Details: [security](../../security.md).
