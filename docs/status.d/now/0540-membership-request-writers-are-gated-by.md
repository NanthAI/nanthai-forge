Membership request writers are gated by the default-off `FORGE_MEMBER_APPROVAL_REQUESTS`
rollout flag. Email lookup requires a verified address. Full Work archive listing and
exchange require owner or contributor membership; accepted-source clones keep their source
path for signed-in readers. Clone, fetch and web archive downloads require sign-in on
public projects too; public file views return rendered pages without object URLs. Device starts default to 120/minute;
anonymous clone budgets and counters have been removed. Details and call budgets: [security](../../security.md).
