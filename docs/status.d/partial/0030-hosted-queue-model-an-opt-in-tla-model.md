- **Hosted queue model.** An opt-in [TLA+ model](../../../models/landing-queue/README.md) checks bounded queue safety/liveness and incident shapes. The default checks S2-reuse, which requires an exact pass or a recomposition with disjoint check inputs. Litmus configurations demonstrate the literal exact-tuple counterexample and catch a broken overlap guard. A source phase-name guard runs with foundation checks. This is not a proof of the implementation or live provider recovery. Same-group prefix conflicts stay advisory until the included group settles, then retry on accepted main without agent action. Conflicts independently proven against main still report promptly; both source workers and deterministic cohort regressions guard the distinction.
