Project search (⌘K / Ctrl+K) reads Intents, Lanes, Views and available files through existing local and hosted APIs; empty search shows a short Needs-you/recent list and queries group up to five matches per type with Show all. An id (8+ hex characters or a full UUID, any case) leads with the Intent, Item, Lane, View or landing it names; one the page does not hold costs one debounced lookup, the planning search and the receipt read sent together, and an idle palette makes no calls. In the rebuilt app, Go to or run (⌘K, or the search icon on a phone) finds an Item, Lane or landing by a pasted id the same way: one debounced lookup through the planning search, the Lane id resolver and the receipt read, then Enter opens an Item in Plan, a Lane on its page and a landing on its Lane (or its receipt). In both palettes a read that fails drops only its own results. Mobile has a search icon, full-screen palette and Now decision badge. Work headings share an inline collection switcher; incomplete filter counts and unavailable Planning counts are omitted. The top-bar Needs-you count shares Now’s decision source and session-local snoozes; Theme lives in the initials avatar menu as system/light/dark icons; the retired Appearance route redirects to General. Access shows names and handles, supports handle autocomplete and private pending invitations accepted by their invited account. Contributions collapses to one sentence when empty.
