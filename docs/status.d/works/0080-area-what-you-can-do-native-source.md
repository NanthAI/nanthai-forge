| Concurrent acceptance | Accepting never drops another accepted change. | Hosted landing gate | `acceptance.gate` is `full` (absent) or `contract`, set with the owner `set-policy` action; the supervised preset sets `full`, the trusted and autonomous presets set `contract`, and a project without a preset reads as `full`. With `contract`, an eligible agent's Candidate (the owner's agent by default; with `acceptance.autoActors` set, exactly the listed agents; with `trust.enabled`, another agent once trust lifts it above supervised on the Candidate's paths) whose Intent declares a contract is accepted on a passing contract run (declared tests, changed tests, composed Intent union) on the exact Candidate; supervised acceptance, unlisted or untrusted contributors, people, system changes, Intents without a contract, protected or unknown paths, and red or audit-debt main keep the full gate, and contract-only evidence never satisfies them. A full or docs pass satisfies either gate. A check definition may opt in to `docsPaths` ([docs-only paths](../../pre-queue-checks.md#docs-only-paths)): a docs-only change then runs no command and a clean Markdown overlap outside tests lands on its first check; the default runs everything. Main may be briefly red; the [asynchronous main audit](../../agents/workflow.md#main-audit-cadence) (one in flight, with a project-derived wake threshold) and automatic recovery revert a single proven culprit through an ordinary landing or open a fix-forward Intent, never rewinding main. The dogfood project runs `contract` since 2026-10-30 (revert with `gate: full`). A hosted entry with no progress for 15 minutes raises `LANDING_STALLED`; a queued one that Forge cannot re-drive and nothing live is driving is ended after 60 minutes as `terminal-failed` with a stated reason (nothing landed; land the same Lane again). Stall alerts by email or webhook are on by default (`stallAlerts`) and need recipients or a webhook configured. The same channels send one alert when a per-landing speed or cost budget breaks over its rolling window, and one recovery when it returns within budget ([speed budgets](../../agents/speed-budgets.md)). |
