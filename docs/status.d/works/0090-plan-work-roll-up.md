Plan Item Work pages retained landing receipts and their exact Code States, plus
related Item titles from open and settled work. Initiative Progress rolls up open
Lanes, landing receipts and files touched across its Items. It reads a bounded
summary independent of landing history and has no pager. Both make zero idle calls.
Initiative Progress names the person accountable and links its count of active agents
to Lanes.
Plan, Initiative detail, CLI and MCP share the five Initiative status counts and their
total. Members use the maintained counter when it proves coverage, including beyond
the Plan display window. Bounded Plan counts show a lower bound when coverage is incomplete.
Visitor, legacy and filtered counts use bounded indexed pages.
See [Item Work](../../planning.md#item-work).
