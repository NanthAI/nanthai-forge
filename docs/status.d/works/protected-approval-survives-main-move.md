An owner's protected-path approval on a held landing stays valid when main moves and
does not touch the approved protected files, even if main changed other files the Lane
also changed. It asks again when main or the Lane changes a protected file, when the
hold has another reason, or when Forge cannot prove the protected content is the same.
A later held submission of the same work (a fix after a failed check, or a resolution
Lane's) reuses that approval for the same protected change; the agent stays the acceptor,
so other review rules still apply.
