- **Agent questions and hand-back.** The agent CLI and `forge_task` record
  fixed-choice questions on one Lane or Item, and hand a saved Lane back to its
  person or the project owner. A chosen answer and resume prompt remain available
  through the coordination inbox. The commands reuse coordination events and
  replace board post/reply and the separate coordination send shortcuts.
