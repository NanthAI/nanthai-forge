- In the rebuilt app, Settings, Project shows the project's name, address, visibility,
  owner and created date; the owner renames it, moves it to the trash, reads its stored
  checkpoints (download and recovery request), stores an archive and removes an import.
  Account, Projects has a Trash section: projects you moved there, soonest to go first,
  with Restore, Delete forever (type the project's name) and Empty trash, which opens the
  existing delete request. Restore's Undo trashes the project again only while it is exactly
  as that restore left it: a restore returns a receipt, and the Undo is refused if another
  tab restored first, anything changed, or someone accepted an invitation since. The archive
  picker is a button and the chosen file's name, not the browser's own input. Visibility is shown; no screen or call changes it yet.
