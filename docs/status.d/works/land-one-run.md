Land names its cheap refusals first: a dirty Lane, stale Lane pins and a missing
queue proof come back together, before any heavy-slot wait, preflight or
compose. Queue proof refusals list every path with its own next step, and name
files no replay can reach. A proof a peer's landing made stale is kept while
the Lane keeps its proven bytes, and the landing check re-runs its replay. A land that stopped on a transient failure or the
preflight budget resumes instead of restarting. Preflight runs budget and
contract guards early, kills a test file past its per-file limit and names it,
and leaves no process running after it exits. It fits ranked tests to the run
ceiling and names deferred coverage in the detailed plan. The healthy path
adds no calls.

An ordinary disjoint Lane composes on newer main using its saved source. A
known conflict with main or recovery from a failed check still calls for a sync.
Foreground landing prints compact changes in phase, hold, order wait or stall
from its existing feed. A fresh diff in the Lane waits for its pending split save
before choosing the saved head.
