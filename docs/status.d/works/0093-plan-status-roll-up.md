Planning status follows linked Work and settled child Items by default. The Plan worker writes an ordinary Version with the rule that moved each Item or Initiative; CLI, MCP and the web read that same status. Manual changes pin the status until **Follow work** clears it. Batch Undo restores the previous pin. Turning roll-up off keeps an Item’s own start and completion behavior; turning it back on starts a bounded catch-up on the selected Plan partition; regular CLI and MCP Plan reads report its progress and any stop reason. The Board shows each Initiative’s status and its Items done count, with no inactivity-driven status. See [Status roll-up](../../planning.md#status-roll-up).
