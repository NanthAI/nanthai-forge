- [Link work to Items](../../planning.md#link-work-to-items) is on by default. An agent's new unplanned Lane captures a plain, members-only Item in a project with a ready Plan. The captured Item is readable by ID as soon as start returns. The Plan wake updates lists and search after start. Owners can turn future capture off; no model or polling runs. [Agent refinement](../../planning.md#title-only-capture-and-optional-agent-refinement) is separate and off by default. When enabled, an explicit request prepares one Item for suggestions in the agent's own tool.
