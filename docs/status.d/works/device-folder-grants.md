A device can be limited to folders of one project. Saves outside them and
reverts stop with `AUTH_SCOPE_DENIED`. The grant ends 7 days after its last write or 30 days
after it was given (`AUTH_EXPIRED`), renewing at most hourly on a write, with
no extra read or idle call. Landings say whether an agent or a person built
them, and History and `landings {kind}` filter by it. The GitHub device check
keeps the typed code through its return and is offered only to an account with
linked GitHub.
