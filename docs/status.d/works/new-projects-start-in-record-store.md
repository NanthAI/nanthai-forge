- **New projects keep their Work in the record store.** A project born under
  server authority with no Work commands yet (created in the app, imported from
  GitHub, made editable, or hosted from a plain folder with `nforge host`) starts
  in the record store with every writer primary, the mode the Forge project runs.
  The birth transaction sets it in its existing project patch and its receipt
  says so. Still journal-only at birth: a Git worktree host and a project
  allocated by an archive upload, and a plain folder whose Work already ran
  commands. Converting existing journal-only projects is still open.
