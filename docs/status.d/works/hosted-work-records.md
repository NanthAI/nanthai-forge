- **Hosted Work records.** Hosting a native folder, Git worktree or archive verifies and imports Work before publishing the selected generation. Hosted Work uses one record format. Planning lists, history and audits read canonical records. The retained event windows still reopen older journal events, including anchored notes and comment purges. Archived Item snapshots remain readable. See the [P8 migration runbook](../../operations/legacy-work-store-mode.md).
