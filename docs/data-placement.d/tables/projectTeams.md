| `projectTeams` | One row per project and linked team with that team's role, `read` or `write` (Item b6588425, docs/access.md#teams). A separate row, not a field on the project or team, so a team is reusable across projects and later ownable by an organization. Written only by the owner person (`projectTeamAccess.set`), with the project's `teamLinks` count and `teamRevision` in the same transaction; at most 50 per project. Read by `teamGrant` only when `teamLinks` is set and the direct grants miss, so owners, direct members and projects without teams read none. Deleted when the team is purged, the project is trashed (with the direct grants) or the project is purged. | Fixed per link (~120 B); no per-landing or idle cost |
