## Web response headers

The hosted web app is sent with `X-Frame-Options: DENY`, an enforced `Content-Security-Policy`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, HSTS and a restrictive `Permissions-Policy`, set in `site/headers.ts` (as `_headers` for static files and on every site Worker response). The policy allows scripts only from the site, the inline theme script's hash and WebAssembly (no third-party script origins, no `'unsafe-inline'` or `'unsafe-eval'` scripts), and forbids framing (`frame-ancestors 'none'`) and embedding frames (`frame-src 'none'`), plugins and a changed base URL. Zod runs jitless in the browser (`web/src/zod-jitless.ts`) so it never evaluates strings. `tests/web-headers.test.mjs` checks the block, that the inline theme script's hash matches `web/index.html`, and that the web entry loads the jitless setting first.
