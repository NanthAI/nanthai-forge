### Incremental hosted source exchange

Use `nforge exchange --help` and [source exchange](../../../operations/source-exchange.md) for pull, open, restore and migrate request files. Sign in with `nforge login`. Request files carry no credentials. Save and land through the hosted Lane commands. Archive migration keeps source, Work, artifact bytes and historical IDs, and can retire the old compressed container. Retain original operation IDs to recover an interrupted request.
