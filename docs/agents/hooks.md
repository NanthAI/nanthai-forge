# Installed agent hooks

Rule: **a hook guards or informs about the action happening now (this edit, this stop).** Anything that arrives later (board notes, notices, messages) rides on command replies and on `wait`, never on a hook. Every hook costs zero while idle and fails open.

`nforge` installs hooks for Claude Code (`~/.claude/settings.json`) and Codex (`~/.codex/hooks.json`) on the first run of an installed CLI, and `nforge connect antigravity` installs Antigravity's hook (`~/.gemini/config/hooks.json`). Any legacy Forge `UserPromptSubmit` entry is stripped on install and never added.

## Installed hook behaviours

| Behaviour | Hook & client | Call cost | Fail-open | Rule check & reason |
| --- | --- | --- | --- | --- |
| Refuse tracked-source edits in the project's main copy (`cloneRootRefusal`) | `PreToolUse` (`Edit`, `Write`, `MultiEdit`, `NotebookEdit`, `apply_patch`) on Claude Code & Codex; `PostToolUse` → `PreInvocation` warning on Antigravity | 0 hosted calls; local stat of `.forge/hosted-main.json` and root ignore files; idle 0 | Yes (1 s worker deadline; errors return `''` and continue) | **Kept (fits rule).** Directly guards the edit happening now: edits in the main copy are never saved or landed and block the next pull. |
| Warn once per session on non-refused clone-root edit (`cloneRootHint`) | Same as above | 0 hosted calls; local `PeersCache` read/write; idle 0 | Yes | **Kept (fits rule).** Directly informs about the edit happening now when a clone-root path is not refused (for example an ignored path). |
| Warn on edit during an in-flight landing (`laneEditHints` → `liveLanding`) | Same as above | 0 hosted calls; local read of `$XDG_STATE_HOME/forge/lanes/<laneId>.json`; idle 0 | Yes | **Kept (fits rule).** Directly guards the edit happening now: an edit made while a landing runs is not included in that landing. |
| 30-minute unsaved-edit reminder (`laneEditHints` → `UNSAVED_HINT_MINUTES`) | Same as above | 0 hosted calls; local `statSync` on `.forge/hosted-lane.json` + local `PeersCache`; idle 0 | Yes | **Kept with reason (borderline).** An agent editing for 30+ minutes without running a Forge CLI command sees no command replies; warning on the edit costs zero hosted calls and guards the active unsaved stretch. |
| Show peers' manual claims, unsaved "touching" claims, and saved unlanded changes on the written path (`readHostedEditPeers`) | Same as above | At most 1 bounded `projectHostedOverlaps:read` per uncached `(laneId, session, path)` when the server advertised `agent-board`; cached repeats 0; idle 0 | Yes (650 ms RPC timeout, 1 s supervisor deadline; errors emit incomplete coverage and continue) | **Kept (fits rule).** Directly informs about concurrent edits to the exact path being written right now. |
| Background automatic "touching PATH" claim write (`queueBoardClaim` → `board-claim-sender.js` → `projectBoardClaims:claim`) | Same as above (`PostToolUse` on Antigravity) | 0 calls on the hook's path (local spool append + lock + at most 1 detached sender per Lane); sender batches over 1.5 s into 1 mutation per ≤10 new unsaved paths under `agentDefaults.autoClaim`; idle 0 | Yes (detached `unref()`, never blocks edit; any error drops the claim) | **Kept with reason (borderline).** Records the unsaved edit happening now so concurrent peers editing the same path see it before either Lane saves; cannot wait for a `save` command reply. |
| Unread board notes on first write (former `board.messages` delivery) | Removed from first-write hook (Item `f3495abe`) | Saved 3 `projectBoardInboxes` point reads + message scans per uncached first write | — | **Moved to command replies and `wait` (broke rule).** Later-arriving project, Issue and Lane notes are unrelated to the file being edited and duplicate next-command delivery. |
| Antigravity `PostToolUse` → `PreInvocation` notice handoff (`agent-antigravity-hook.js`) | `PostToolUse` + `PreInvocation` on Antigravity | `PostToolUse` runs the shared first-write check; `PreInvocation` is local-only (Node builtins, atomic rename + read + unlink of per-conversation file); idle 0 | Yes (never throws, always answers `{}` on error; never blocks writes) | **Kept (fits rule).** Delivers only the first-write check's notice on a client whose `PreToolUse` cannot return context without overriding user permissions. |
| Block first `Stop` while session owns unfinished Forge work (`turnEndDecision`) | `Stop` on Claude Code & Codex (see Codex live gap Item `2f13b3cf`) | 0 when idle or live/warm (<30 s) observer; at most 1 bounded hosted query (`projectHostedCheckRead:status` or `projectHostedFinishObserve:page`, 2.5 s deadline) on cold cache | Yes (any error, timeout or unconfirmed state returns `{}`; second consecutive stop always passes) | **Kept (fits rule).** Directly guards the `Stop` happening now so an agent does not abandon a running landing or check. |
| Turn-end unsaved-work snapshot (`turnEndWithSnapshot` → `turnEndSnapshot`) | `Stop` on Claude Code & Codex (allowed stop only, inside a Lane with `autoSnapshot` on) | 0 when `autoSnapshot` is off, outside a Lane, or tree unchanged; uploads changed files only (3.5 s abort inside 5 s timeout); idle 0 | Yes (advisory; errors swallowed and never change the `Stop` decision) | **Kept (fits rule).** Directly guards the `Stop` happening now by capturing edits made after the last Forge command before the turn ends. |
