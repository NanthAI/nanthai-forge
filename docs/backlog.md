# Backlog

The backlog is Forge planning, not this page. Initiatives group Issues, and each Issue carries its own **Done when** list. Read it with the planning action:

```sh
nforge agent ROOT planning '{"status":"open","limit":50}'
```

Start work from an Issue (`start '{"planningItemId":"ISSUE_ID"}'`), so the Lane, the Intent and the evidence stay linked. The [roadmap](roadmap.md) sets order and scope, and [status](status.md) says what works today.

This page once listed open items by hand. That list is in version control history; many of its items referred to code that has since been deleted.
